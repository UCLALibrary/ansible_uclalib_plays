<summary>Clearing a TODO</summary>

Mark the TODO as done by adding an `x` to the checkbox, then move the completed
record to the end of the file. If there are no more TODOs for the given date,
then remove the subheading:

```markdown
- [x] Inspect codebase for Y2k
```
